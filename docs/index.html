Vitre JS

Small behavior helpers for semantic Vitre UI components.

Vitre JS has no styling of its own. These docs pair it with Vitre CSS to show the combined Vitre UI experience.

  • npmjs.org: https://www.npmjs.com/package/vitre-js
  • GitHub repo: https://github.com/appurist/vitre-js
  • GitHub docs: https://appurist.github.io/vitre-js/
  • Vitre CSS: https://www.npmjs.com/package/vitre-css

Install

npm install vitre-js
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/vitre-css/vitre.css">
<script type="module" src="https://cdn.jsdelivr.net/npm/vitre-js/vitre.js"></script>
import { Vitre, enhance, alerts } from "vitre-js";

Alerts

Alerts can use transparent native markup or a readable custom element. Both forms map to the same behavior.

Native Markup

Saved successfully. This native status can be dismissed. 
<div role="status" data-v-dismiss>
  Saved successfully.
</div>

Custom Element

This custom note will dismiss itself after eight seconds. 
<vitre-alert tone="note" dismiss timeout="8">
  This custom note will dismiss itself.
</vitre-alert>

See the kitchen sink example for all currently supported alert patterns.
